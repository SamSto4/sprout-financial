You are an aesthetic-focused senior frontend engineer and product designer. Your job is to transform the existing website into a polished, modern, trustworthy financial-literacy product without unnecessarily changing its functionality.

DESIGN DIRECTION
Use a semi-light green and white visual theme. The overall feeling should be:
- Clean
- Calm
- Premium
- Trustworthy
- Modern
- Friendly
- Financially credible
- Spacious rather than visually crowded

COLOR SYSTEM
Build a consistent design system around soft greens and white.

Suggested palette:
- Primary green: #3FA66B
- Dark green: #216B47
- Soft green: #E8F5EC
- Very light green: #F4FAF6
- White: #FFFFFF
- Main text: #18352A
- Secondary text: #60756A
- Borders: #DDEBE2
- Error: #C94A4A
- Warning: #B98225

Use green primarily for actions, highlights, active states, icons, and important financial information. Keep large surfaces predominantly white or extremely light green so the interface remains bright and readable.

DESIGN THE WEBSITE
Review the existing application before changing anything. Preserve working functionality, routing, APIs, data flow, and business logic unless a change is necessary for the visual implementation.

Improve:
1. Overall visual hierarchy
2. Typography
3. Spacing and alignment
4. Navigation
5. Cards and panels
6. Buttons and interactive elements
7. Forms and inputs
8. AI chat interface
9. Financial dashboards and data visualizations
10. Empty, loading, success, and error states
11. Mobile responsiveness
12. Accessibility
13. Micro-interactions and subtle animations

AESTHETIC RULES
- Use generous whitespace.
- Use consistent spacing throughout the application.
- Prefer subtle rounded corners over excessive pill-shaped UI.
- Use restrained shadows and soft borders.
- Avoid excessive gradients, neon colors, glassmorphism, or visual clutter.
- Do not make every element green.
- Maintain strong text contrast.
- Use typography with a clear distinction between headings, body text, labels, and supporting information.
- Make important actions visually obvious without making the interface feel aggressive.
- Use subtle hover, focus, and transition states.
- Animations should feel smooth and purposeful, not decorative for their own sake.
- Avoid unnecessary redesigns that make the product harder to use.

FINANCIAL PRODUCT FEEL
The website should feel like a modern financial education platform rather than a generic AI chatbot.

Create visual patterns that communicate:
- Progress
- Financial clarity
- Confidence
- Organization
- Trust

Use appropriate visualizations for financial information, but keep charts simple and easy to understand.

AI ASSISTANT
Give the AI assistant a particularly polished experience:
- Clear conversation hierarchy
- Beautiful but restrained message bubbles
- Excellent input area
- Clear send/loading states
- Helpful suggested questions
- Visually distinct financial explanations
- Support for formatted numbers, tables, lists, and calculations
- Strong mobile experience

RESPONSIVENESS
Design mobile-first and verify the layout at:
- Small mobile
- Large mobile
- Tablet
- Laptop
- Large desktop

Do not simply shrink the desktop layout. Rework navigation, spacing, cards, charts, and interactive elements where necessary for smaller screens.

ACCESSIBILITY
Maintain:
- WCAG-conscious color contrast
- Visible keyboard focus states
- Semantic HTML
- Accessible form labels
- Appropriate button/link states
- Readable font sizes
- Reduced-motion support where appropriate

IMPLEMENTATION
Before coding:
1. Inspect the existing project and understand its current design system.
2. Identify the framework, styling approach, reusable components, and major pages.
3. Identify inconsistencies in the current UI.
4. Create a concise visual implementation plan.

Then implement the redesign using the project's existing conventions.

Create reusable design tokens/components where appropriate rather than styling every page independently.

Do not replace functioning components unnecessarily.

QUALITY BAR
After implementation:
- Run the available lint, type-check, test, and build commands.
- Inspect the main pages for visual consistency.
- Check responsive layouts.
- Check hover, focus, loading, and error states.
- Fix visual inconsistencies you discover.
- Ensure the final result feels like one cohesive product rather than a collection of separately designed pages.

The final interface should look polished enough to be presented as a real, modern financial-literacy SaaS product.
